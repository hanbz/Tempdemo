# 晴光苑・3D 預售屋線上賞屋 Demo

以 [three.js](https://threejs.org/) 製作的預售屋 3D 看屋介面，所有建築、格局與家具皆由程式即時生成，不需任何 3D 模型檔。建案「晴光苑」為虛構的示範資料。

## 功能

| 模式 | 說明 |
| --- | --- |
| **建案外觀** | 16 層住宅大樓與周邊街廓。每一戶依銷控狀態上色（可銷售／已預約／已售出），滑過可看戶號、坪數、總價，點選即切換戶別。 |
| **3D 格局** | 去掉天花板的「娃娃屋」視角，可旋轉縮放；拖曳「牆面高度」可做剖面。點房間標籤會飛到該空間。 |
| **室內漫遊** | 第一人稱視角，拖曳轉頭、點地板走過去，或用 WASD／方向鍵行走，含牆面與家具碰撞。窗外景色會隨所選樓層高度改變。 |
| **平面圖** | 俯視剖面平面圖，標示每個房間的坪數。 |

其他：

- 左側資訊卡：樓層／戶號選擇、主建物／陽台／公設／權狀坪數、單價與總價試算（依樓層與邊間加價）
- 空間配置清單：每個房間的尺寸與坪數，點選即前往
- 三種裝潢風格（現代簡約、北歐暖木、工業風）即時切換材質
- 日照時間滑桿：太陽方位、陰影、天空顏色連動；入夜後室內燈與大樓窗戶亮起
- 右下角小地圖：顯示目前位置與視角，點選可瞬移
- 預約賞屋表單（展示用，不會送出資料）
- 手機版：資訊卡收合為底部抽屜，支援觸控拖曳與雙指縮放

## 執行

純靜態網頁，three.js 由 CDN 載入。因使用 ES modules，需透過本機伺服器開啟（不能直接雙擊 `index.html`）：

```bash
python3 -m http.server 8000
# 瀏覽器開啟 http://localhost:8000
```

網址可加上 `#dollhouse`、`#walk`、`#plan` 直接進入對應模式。

## 檔案結構

```
index.html          介面骨架
css/style.css       樣式（含深色模式、手機版）
js/main.js          場景、相機、模式切換、互動與 UI
js/units.js         建案設定、A／B 戶型格局資料、坪數與價格計算
js/unitModel.js     由格局資料生成牆面、門窗、地板、天花板與碰撞資料
js/furniture.js     程式化家具（沙發、床、廚具、衛浴…）
js/materials.js     材質、程序貼圖（木地板／磁磚）與裝潢風格
js/exterior.js      大樓外觀、銷控量體與周邊城市
```

## 換成真實建案

- 修改 `js/units.js` 的 `PROJECT`（建案名稱、樓層數、單價、公設比）
- 依實際平面圖改寫 `UNITS` 內的 `rooms`（房間範圍，單位公尺）、`walls`（牆線與門窗開口）、`furniture`（家具擺設）
- 銷控狀態目前由 `unitStatus()` 產生假資料，可改為呼叫後端 API
- 若有建築師提供的 glTF 模型，可用 three.js 的 `GLTFLoader` 取代程式生成的戶型
